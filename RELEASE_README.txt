Squidarr Proxy — Windows quick start

1. Copy config.env.example to config.env.
2. Set a private API_KEY and your DOWNLOAD_PATH in config.env.
3. Set DEEZER_API_KEY to enable Deezer downloads. Keep credentials private.
4. Run start_squidarr.bat.
5. Open client\index.html and enter the proxy URL and API key.

Defaults such as PORT=8687, CATEGORY=music, and TZ=Europe/Paris do not need to
be added to config.env. Optional Qobuz credentials can be configured there.

Do not upload or share your actual config.env publicly.
